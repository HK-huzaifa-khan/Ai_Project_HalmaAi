Halma Board Game with AI Opponent
Overview:
A Python implementation of the classic Halma board game featuring:

~Human vs AI gameplay with 3 difficulty levels
~Minimax algorithm with alpha-beta pruning for smart AI moves
~Pygame GUI with intuitive piece selection and movement
~Win condition: Move all your pieces to opponent's starting zone

Features
Turn-based gameplay with black/white pieces
Visual move validation and highlighting
Smart AI opponent (Easy/Medium/Hard)
Clean board visualization with starting zones
